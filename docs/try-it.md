# Try it

Try it now opens VEMI with nothing to set up. This is local mode: VEMI runs inside this browser, on this device, with no account.

## What it is

- Your data is kept in this browser. Nothing is sent anywhere: there is no server holding it and no sign-in.
- It works offline, because there is nothing to reach.
- It has everything for planning: spaces, projects, milestones, tasks, Today, smart dates and locked notes.

## What it lacks

- Push reminders when VEMI is closed. Reminders show while the page is open.
- AI. The connector needs a copy of VEMI with an address your own Claude or ChatGPT can reach, so local mode has none.
- People. Nobody can be invited, and there is nobody to share with.
- Sync between devices. What you add here stays on this device and this browser.

## Keep it safe

Clearing the browser's site data for this page deletes everything you made here. So does a browser that clears data it thinks you do not use. The only ways back are a file you exported or a copy you moved to.

In Account, under Your data, press Export everything now and then. A file you keep restores into any copy of VEMI.

## Move to my own cloud

When you want your data kept for good, in your own free Cloudflare account, use Move to my own cloud. It is on the Account screen in local mode.

1. Press Move to my own cloud. It opens the setup helper with the move switched on.
2. Pick your export file. The helper builds your new copy and moves the file into it.
3. Open your new copy and sign in with the email and password you gave the helper.

The data goes from this browser to your new copy and nowhere else. It never goes through the front door that served the page, and it never goes through the relay the helper uses to talk to Cloudflare. Neither can see it.

### If you already have a copy

Press I already have a copy. VEMI asks for the copy's address and a move code.

1. In the copy you already have, open Account, then Your data, then Move code, and press Make a code. The code is good for 15 minutes, once.
2. Back here, type the address and the code, then press Check that copy.
3. VEMI shows what is on this device and what is in that copy now. Moving replaces what is in that copy. Type replace to go ahead.

After a move, Clear this device empties the browser's copy: the database, the saved keys and this session.

### Locked notes

Locked notes stay locked on the way. Before anything is sent, a file that holds them asks for one of its own ways in: a Face ID or fingerprint passkey, the vault password or the recovery key. VEMI opens the file with it, then lets the key go at once. Nothing sends it or keeps it.

Your new copy asks for the file once more to finish, because that address never held it, and locks each note again for the new account. A passkey stays with the device it was made on, so add a passkey in your new VEMI to open locked notes there. Any note that could not be opened stays as the file had it.
